Stack-chan Flasher

M5Stack CoreS3 にファミコンエミュレータを USB で書き込み、WiFi と ROM を設定します。

このブラウザでは使えません

書き込みには Web Serial API が必要です。デスクトップ版の Chrome または Edge で開いてください (Safari・iOS・Android は非対応です)。

ブラウザを使わずに書き込む場合は just flash が従来どおり使えます。

Step 1

ファームウェアを書き込む

CoreS3 を USB で繋いで「書き込む」を押し、表示されるダイアログでポートを選んでください。

Step 2

接続する

書き込みの後、CoreS3 は USB ポートを繋ぎ直します。もう一度ポートを選んでください。

Step 3

WiFi を設定する

公開しているファームウェアに WiFi の設定は含まれていません (誰にでも配るバイナリに 認証情報は焼けないため)。ここで送ると本体の NVS に保存され、再起動しても残ります。

Step 4

ROM を SD カードに入れる

.nes ファイルを選ぶと、USB 経由で本体の SD カードに保存します。 中継サーバー (just serve) は要りません。
